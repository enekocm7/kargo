# CLAUDE.md

Kargo is **Cargo for Kotlin**: a build tool and package manager written in Rust that builds Kotlin projects for the JVM, WebAssembly, JavaScript, Kotlin/Native and Android from a single `kargo.toml`.

## Reminder

Documentation is part of every change. If your change affects a command, flag, `kargo.toml` key, framework, environment variable, lockfile behavior, layout, toolchain, or default version, update the matching page in `website/src/content/docs/` in the same change. `README.md` is a short landing page, not a copy of the docs: touch it only for headline changes (a new target or framework, the install commands, the everyday commands it lists). If no existing page covers it, create a new page and add it to the sidebar in `website/astro.config.mjs`. The mapping of changes to pages and the steps for a new page are in `AGENTS.md`.
