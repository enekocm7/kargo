# Task

I want you to build a tool like cargo in rust but for kotlin, it should be able to create projects, add maven dependencies, run,build and test the project

# Specifications

Use kargo.toml as the config file
Can compile to jvm, wasm and kotlin/Native
It has to be production ready so test everything
Add android compilation
Can add maven repository dependencies and plugins
Make a cli like cargo
Make it extensible with tasks and plugins
Add built-in tecnologies like compose, kotlinx Serialization, Ktor, Lombok and Spring Boot

# Guide

Commit every change like a normal developer would do, just commit to master.
Use the rust skills to write good rust following good practices
Use a workspace and multiple crates to speed up compilation and make it more composable
