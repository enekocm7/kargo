# Kargo for Visual Studio Code

Kargo projects in VS Code: `kargo lsp` for Kotlin and `kargo.toml`, the Kargo commands as tasks with their compiler errors in the Problems view, a test explorer, Run and Debug buttons above `fun main` and the tests, debugging through `kargo dap`, and a status bar for the target and profile.

Open a folder that has a `kargo.toml` at its root. The extension needs [Kargo](https://enekocm7.github.io/kargo/getting-started/installation/) on your `PATH`, or its path in the `kargo.path` setting.

Full documentation, including the settings and the commands: [Visual Studio Code](https://enekocm7.github.io/kargo/guides/editors/#visual-studio-code).
