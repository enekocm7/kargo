# Kotlin/JS

A Kotlin/JS application, built without Gradle.

```sh
kargo run -t js
kargo test -t js
```

Guide: [JavaScript (Kotlin/JS)](https://enekocm7.github.io/kargo/guides/js/)

This project is a copy of what `kargo new` generates (see the [examples index](../README.md)), so it tracks Kargo's current default versions.
