# Multiplatform library

A serializable library that compiles for the JVM, JavaScript and Wasm.

```sh
kargo build
kargo test
kargo package
```

Guide: [Multiplatform projects](https://enekocm7.github.io/kargo/guides/multiplatform/)

This project is a copy of what `kargo new` generates (see the [examples index](../README.md)), so it tracks Kargo's current default versions.
