# Hello, JVM

The smallest Kargo project: one JVM application with a unit test.

```sh
kargo build
kargo run
kargo test
```

Guide: [Your first Kotlin app](https://enekocm7.github.io/kargo/guides/first-app/)

This project is a copy of what `kargo new` generates (see the [examples index](../README.md)), so it tracks Kargo's current default versions.
