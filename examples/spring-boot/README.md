# Spring Boot

A Spring Boot web application with the `web` starter, written in Kotlin.

```sh
kargo run
kargo test
kargo package
```

Guide: [Spring Boot](https://enekocm7.github.io/kargo/guides/spring-boot/)

This project is a copy of what `kargo new` generates (see the [examples index](../README.md)), so it tracks Kargo's current default versions.
