# Ktor server

A Ktor server on Netty with kotlinx.serialization, listening on port 8080.

```sh
kargo run
curl http://localhost:8080/
kargo test
```

Guide: [A REST API with Ktor](https://enekocm7.github.io/kargo/guides/ktor/)

This project is a copy of what `kargo new` generates (see the [examples index](../README.md)), so it tracks Kargo's current default versions.
