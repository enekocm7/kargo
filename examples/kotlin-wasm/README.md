# Kotlin/Wasm

A Kotlin/Wasm browser app with coroutines.

```sh
kargo run -t wasm
kargo test -t wasm
```

Guide: [WebAssembly](https://enekocm7.github.io/kargo/guides/wasm/)

This project is a copy of what `kargo new` generates (see the [examples index](../README.md)), so it tracks Kargo's current default versions.
